A program that writes one deadpan weather forecast for the fictional city
of Dullmere to `/output/entry.txt`, for the make.fun competition
[Deadpan Forecasts for Cities That Do Not Exist](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c).

Run it with Python 3:

```
python3 main.py
```

It writes the forecast below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The forecast is 157 characters, inside the 1 to 160 gate.

## The forecast

```
In Dullmere, a high of 11 degrees, a low of 10, and drizzle that has been falling since 2019. Locals no longer notice. Visitors are issued towels on arrival.
```
